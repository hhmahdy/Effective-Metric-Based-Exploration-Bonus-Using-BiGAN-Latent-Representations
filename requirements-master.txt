# Installation
# ------------
#   python -m pip install -r requirements-master.txt
#
# Platform note (important, do not misread the torch pin)
# -------------------------------------------------------
#   `pip install torch==2.14.0` on Linux resolves to the CUDA build
#   (2.14.0+cu130) and pulls several gigabytes of NVIDIA runtime wheels
#   (cuda-toolkit/cublas/cudart/cudnn/nccl/...). That is expected and works on
#   machines without a GPU as well -- the runs in this project select the
#   device explicitly through `--device {auto,cpu,cuda}`.
#   For a CPU-only installation use the PyTorch CPU index instead, which is
#   platform dependent and therefore not pinned here:
#
#       python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
#       python -m pip install numpy==2.4.6 gymnasium==1.3.0 ale-py==0.12.1 \
#           matplotlib==3.11.2 tensorboard==2.21.0
#
#   The code itself targets Python 3.9+ and PyTorch 2.x (see README); the pins
#   above are the versions used for verification, not a hard lower bound.
#   Exact CUDA wheel availability varies by platform, so no CUDA-specific
#   package is pinned in this file.
