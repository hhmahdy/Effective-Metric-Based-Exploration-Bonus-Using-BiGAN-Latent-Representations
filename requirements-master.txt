# Platform note (important, do not misread the torch pin)
# -------------------------------------------------------
#   `pip install torch==2.14.0` on Linux resolves to the CUDA build
#   (2.14.0+cu130) and pulls several gigabytes of NVIDIA runtime wheels
#   (cuda-toolkit/cublas/cudart/cudnn/nccl/...). That is expected and works on
#   machines without a GPU as well -- the runs in this project select the
#   device explicitly through `--device {auto,cpu,cuda}`.
#   For a CPU-only installation use the PyTorch CPU index instead, which is
#   platform dependent and therefore not pinned here:
#
#       python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
#       python -m pip install numpy==2.4.6 gymnasium==1.3.0 ale-py==0.12.1 \

# MuJoCo pin (important)
# ---------------------
#   `mujoco==3.3.7` is pinned because gymnasium-robotics 1.4.2 cannot construct
#   the Fetch environments against MuJoCo 3.14: MuJoCo 3.14 returns the joint
#   type as a numpy integer, and the membership test in
#   `gymnasium_robotics.utils.mujoco_utils.set_joint_qpos`
#   (`joint_type in (mjtJoint.mjJNT_HINGE, mjtJoint.mjJNT_SLIDE)`) evaluates to
#   False for a numpy integer compared against those pybind11 enum members, so
#   the library's own assertion fails and `gymnasium.make("FetchPickAndPlace-v4")`
#   raises AssertionError. With 3.3.7 the same test succeeds. Loosen this pin
#   only after checking that `gymnasium.make("FetchPickAndPlace-v4")` still
#   constructs.
#
# Optional: the Noisy-TV maze is implemented in this repository, so
# `NoisyTVMaze-v0` needs gymnasium only; only the ORIGINAL Unity build
# (`NoisyTVUnity-v0`) needs the extra pieces below:

#   pillow            the upstream `unityagents` client decodes JPEG frames with
#                     PIL (it is not pinned here because the client itself ships
#                     with the environment repository, not with this project)
#   unityagents       vendored in https://github.com/luchris429/noisy-tv-env;

#                     `make_noisy_tv_environment("auto")` to use the pure-python
#                     reconstruction instead.
